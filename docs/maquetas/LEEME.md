# Maquetas de la interfaz

Fuente de las maquetas del lienzo «Maquetas – Plataforma WhatsApp Exclusivas Gelado» (05/11/2026).
Son la referencia visual obligatoria para la sesión de desarrollo: distribución, nombres, textos y estados.
Siguen la forma de trabajar de Superchat (que el equipo ya conoce) con la identidad de Gelado.

- Cada `*.dc.html` es una pantalla. El marcado y `gelado-app.css` sirven como referencia de estructura, colores y espaciado; no se usan tal cual en la app (la app es React).
- Los datos de las maquetas (nombres de clientes, cifras) son de ejemplo.

| Archivo | Pantalla |
| --- | --- |
| `Main.dc.html` | Bandeja: conversación con ventana abierta, adjuntos, nota de voz, nota interna, ficha lateral |
| `Bandeja-acciones.dc.html` | Menú «…» de conversación, posponer, asignar, etiquetar |
| `Bandeja-plantilla.dc.html` | Ventana de 24 h cerrada y envío de plantilla con variables |
| `Bandeja-biblioteca.dc.html` | Adjuntar desde la biblioteca o desde el ordenador (varios archivos) |
| `Movil-bandeja.dc.html` | Conversación en el móvil |
| `Contactos.dc.html` | Listado de contactos con vistas por tipo de cliente y bajas |
| `Importar.dc.html` | Importación: mapeo de columnas y vista previa del resultado |
| `Campanas.dc.html` | Listado de campañas |
| `Campana-nueva.dc.html` | Nueva campaña: contenido, destinatarios con recuento, programación y coste |
| `Campana-informe.dc.html` | Informe de campaña: embudo, motivos de fallo, destinatarios |
| `Plantilla-editor.dc.html` | Editor de plantillas con vista previa y botón de baja obligatorio |
| `Calidad.dc.html` | Calidad del número, límites, cupo de respuestas gratis y gasto |
| `Ajustes-horario.dc.html` | Horario, respuesta fuera de horario (activada) y modo vacaciones |
| `Ajustes-equipo.dc.html` | Equipo con enlaces de invitación y de nueva contraseña |
| `Login.dc.html` | Inicio de sesión |
